# 2026roboB：足回り・発射機構プロジェクト


## 前提とする基板変更：両基板共通

| 信号 | 現在のPCB | 変更後 | 使用するタイマ |
|---|---|---|---|
| J1 A相、R15 MCU側 | PC4 | PC6 | TIM8_CH1、AF3 |
| J1 B相、R16 MCU側 | PA12 | PC7 | TIM8_CH2、AF3 |
| J2 A相 | PA8 | PA8 | TIM1_CH1、AF1 |
| J2 B相 | PA9 | PA9 | TIM1_CH2、AF1 |
| MD3_PWM2 | PA10 | PA6 | TIM13_CH1、`PA_6_ALT0` |
| MD5_PWM1 | PA11 | PA7 | TIM14_CH1、`PA_7_ALT2` |

古いMCU側接続を外して変更先へ配線します。元のGPIOと変更先を同時接続する形にはしません。J1/J2の5V・GNDおよび直列抵抗は維持します。

元プログラムのJ1宣言はPC5・PC4でしたが、現在のPCBはPC4・PA12です。本プロジェクトでは変更後のPC6・PC7を明示的に使用します。

## モータ・通信の割り当て

| 用途 | PWM1 / PWM2 | タイマ | 反転 |
|---|---|---|---|
| 足回り・左前 MD1 | PB4 / PC8 | TIM3_CH1 / TIM3_CH3 | false |
| 足回り・右前 MD2 | PC9 / PB8 | TIM3_CH4 / TIM2_CH1 | true |
| 足回り・左後 MD3 | PB3 / PA6_ALT0 | TIM2_CH2 / TIM13_CH1 | false |
| 足回り・右後 MD4 | PB10 / PB5 | TIM2_CH3 / TIM3_CH2 | true |
| 発射側・アーム MD1 | PB4 / PC8 | TIM3_CH1 / TIM3_CH3 | false |
| 発射側・ドラム MD2 | PC9 / PB8 | TIM3_CH4 / TIM2_CH1 | false |
| MD5（今回は未使用） | PA7_ALT2 / PB2 | TIM14_CH1 / TIM2_CH4 | — |

TIM1/TIM8は発射側のエンコーダ専用です。PC8/PC9は`_ALT0`を付けず、TIM3を選択します。
| 通信 | 接続 | 設定 |
|---|---|---|
| MU3→足回り | MU3 TX → 足回りPC11、MU3 RX ← 足回りPC10 | 19200 baud、8N1 |
| 足回り→発射 | 足回りPB6 TX → 発射PA1 RX | 115200 baud、8N1 |
| 戻り線 | 発射PA0 TX → 足回りPB7 RX | 今回は返信なし |
| 基板間 | GNDを共通にする | — |
| PCログ | ST-LINK仮想COM、USBTX/USBRX | 115200 baud、8N1 |


## 調整

発射側 `control_config.hpp` を変更します。

| 設定 | 初期値 | 意味 |
|---|---|---|
| ARM_PPR / DRUM_PPR | 2048 | エンコーダ本体の1回転あたり周期数。4逓倍前の値 |
| ARM_ENCODER_SIGN / DRUM_ENCODER_SIGN | -1 / +1 | カウントの正方向。実機で確認 |
| ARM_LOAD_DEG | 90° | 起動・発射開始時のアーム位置からの巻上げ角度 |
| DRUM_STEP_DEG | 72° | 1装填分の角度 |
| ARM_RELEASE_DROP_DEG | 17.578125° | 再始動時の角度から、この角度以上戻ったらモータ停止 |
| POSITION_TOLERANCE_DEG | 2° | 停止位置の許容差 |
| STOP_SPEED_DEG_S | 5°/s | 停止とみなす角速度 |
| SLOW_ZONE_DEG | 6° | 目標直前の減速区間 |
| SETTLE_US | 100000 µs | 低速状態を100ms継続して停止確認 |

2048 PPRは元コードの定数から採用した仮の初期値です。エンコーダ本体のスイッチ設定と一致させてください。1回転で8192カウントなら、この値で正しく360°になります。

旧コードのアーム380カウントは、2048 PPR・2逓倍なら約33.4°です。今回の90°設定はユーザー指定に基づく変更であり、旧停止位置を再現する設定ではありません。必要ならARM_LOAD_DEGを実機の停止位置に合わせて変更してください。

この制御は目標直前で減速し、目標に到達したら既存KKMDの停止操作を行います。PIDによる保持や、停止後に逆回転して誤差を修正する制御ではありません。停止誤差が許容値を超えた場合はFAULTにします。

## 発射シーケンス

1. 起動時はアームの所定の待機位置と、ドラムの初期装填位置に合わせてください。原点センサは未実装です。
2. 足回り側が有効なMU3データを受信し、ボタン値`n`を受信すると発射を受け付けます。
3. `i`への変化で1回だけ開始します。アーム位置を相対0°にして巻き上げます。
4. アーム90°付近でモータを止め、角速度と停止位置を確認します。
5. ドラムを72°ずつ進め、停止確認後にアームモータを再始動します。
6. アーム角度が解放検出量だけ戻ったらモータを止めます。アームが静止してから待機へ戻ります。
7. 次の発射には、待機中に`n`を受信してから再び`i`を受信する必要があります。

ドラムの目標角度は72°→144°→216°と累積します。装填ごとにエンコーダを0に戻さないため、停止誤差を次の目標位置へ足し込みません。アームは各発射開始時の実位置を0°とします。毎回の物理原点の保証は原点センサや機構側の位置決めが必要です。

MU3更新が500ms途切れると足回りを停止し、発射側へ`!`を送ります。基板間UARTが500ms途切れた場合も発射モータを停止します。動作中の通信断・動作タイムアウト・停止位置異常はFAULTとして保持し、確認後にボードをリセットして復帰します。ばね解放後の機械運動をモータ停止だけで止めることはできません。
